# Data

Every chapter runs on **synthetic data generated by code in this repository** (`python/mvg/datasets.py`), so the
ground truth is always known exactly and the notebooks need no downloads. Scenes, images, stereo pairs, marker
images, trajectories and event streams are all rendered on the fly from a fixed random seed.

Files placed here must be small (the whole folder stays under 5 MB) and redistributable. Larger public datasets
are not required by any notebook.
